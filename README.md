# 闲鱼 AI 智能助手 (Xianyu AI Assistant)

闲鱼卖家的 AI 工具箱 — 商品监控 + 智能客服 + 自动运营

## 功能规划

| 模块 | 功能 | 优先级 |
|------|------|:--:|
| 🔍 商品监控 | 关键词监控、降价提醒、新上架通知 | P0 |
| 💬 智能客服 | 自动回复买家、AI 议价、意图识别 | P0 |
| 📦 自动运营 | 自动擦亮、自动发货确认、多账号管理 | P1 |
| 📊 数据面板 | Web 管理后台、数据统计 | P1 |

## 技术栈

- 后端: Python (FastAPI)
- 前端: 单页 HTML (同 trading agent 风格)
- 浏览器自动化: Playwright
- AI: DeepSeek API
- 通知: 飞书 Bot / QQ Bot（现有通道）

## 变现模式

- 工具月费 ¥99-299/人
- 免费版（单账号）+ 付费版（多账号/高级功能）
